# Считывание PDF-файлов (PDF to TXT)

Программа для автоматического считывания и преобразования PDF-документов в обычный текстовый файл `.txt` с использованием искусственного интеллекта.

Программа позволяет извлекать обычный текст, распознавать содержимое сканированных страниц, фотографии, таблицы, графики, схемы и другие визуальные элементы документа.

## Возможности

- Извлечение текста из PDF.
- Распознавание текста на сканированных страницах.
- Распознавание таблиц с сохранением их структуры.
- Обработка PDF пакетами по 10 страниц за один API-запрос.
- Автоматическое сохранение результатов в TXT.
- Возможность обрабатывать весь документ или выбранный диапазон страниц.
- Автоматическое переключение на резервную модель при ошибке основной.

## Используемые технологии

**OpenRouter API** — единый интерфейс для взаимодействия с моделями искусственного интеллекта.

## Используемые AI-модели

Для распознавания документов я решил использовать **OpenRouter**, поскольку он предоставляет единый API для работы с различными моделями искусственного интеллекта.

В проекте используются две модели:

**1. Основная модель — Google Gemma**

`google/gemma-4-31b-it:free`

Используется в первую очередь для распознавания текста, таблиц и визуального содержимого PDF.

**2. Резервная модель — NVIDIA Nemotron**

`nvidia/nemotron-3.5-super-vl:free`

Если основная модель недоступна или возвращает ошибку, программа автоматически пытается использовать NVIDIA Nemotron.

## Получение API-ключа

1. Перейдите на сайт [OpenRouter](https://openrouter.ai/).
2. Зарегистрируйтесь или войдите в аккаунт.
3. Откройте раздел [API Keys](https://openrouter.ai/settings/keys).
4. Создайте новый API-ключ.
5. Скопируйте его для дальнейшей настройки программы.

## Настройка

В начале файла `ocr_pdf.py` необходимо указать название PDF-файла и API-ключ OpenRouter.

Пример:

```python
PDF_FILE = "file.pdf"

OPENROUTER_API_KEY = "ВАШ_API_КЛЮЧ"
```

Остальные настройки уже заданы в программе и при необходимости могут быть изменены.

## Запуск программы

1. Поместите `ocr_pdf.py` и исходный PDF в одну папку.
2. Укажите название PDF и API-ключ в начале скрипта.
3. Запустите программу:

```bash
python ocr_pdf.py
```

После завершения обработки рядом с исходным PDF появится текстовый файл с таким же названием.

Например:

```text
project/
│
├── ocr_pdf.py
├── file.pdf
└── file.txt
```

## Принцип работы

Программа выполняет следующие действия:

1. Открывает PDF-документ.
2. Определяет количество страниц.
3. Разбивает документ на пакеты по 10 страниц.
4. Преобразует каждую страницу пакета в изображение.
5. Отправляет все изображения одного пакета в OpenRouter одним запросом.
6. Основная модель выполняет распознавание содержимого.
7. Если основная модель возвращает ошибку, программа пробует резервную модель NVIDIA Nemotron.
8. Полученный текст сохраняется в TXT.
9. Программа переходит к следующему пакету.

Если в документе меньше 10 страниц, программа отправляет все страницы одним запросом.

## Пример обработки

| Размер PDF | Количество API-запросов |
|---|---:|
| 5 страниц | 1 |
| 10 страниц | 1 |
| 20 страниц | 2 |
| 50 страниц | 5 |
| 100 страниц | 10 |
| 300 страниц | 30 |


## Результат

На выходе получается обычный TXT-файл, содержащий:

- Распознанный текст.
- Заголовки и подзаголовки.
- Абзацы и списки.
- Таблицы в текстовом формате.
